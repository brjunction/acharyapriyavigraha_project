# Taptajīvanam 3.0

The complete, organized home of the teachings of Śrīla Gurudeva, Śrī Śrīmad Gour Govinda Swāmī.

**Status:** clickable design prototype with sample data. The database (Neon) and the real content come next.

- Specification: [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)
- Run locally: `npm install` then `npm run dev`, and open http://localhost:3000 (admin prototype at `/admin`, sign-in screen at `/admin/login`)

Stack: Next.js (App Router) · TypeScript · Tailwind CSS v4 · lucide icons. Planned: Neon Postgres + Drizzle, shadcn/ui, Vercel.
