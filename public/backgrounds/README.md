# Backgrounds

Supplied background artwork, upscaled about 3.6x (ESPCN super-resolution plus light sharpening) to roughly 2200 px and stored as WebP.
Used through `<Backdrop src="name" />` (src/components/backdrop.tsx). In the dark theme they dim automatically.

red-henna-gold, red-gold-mandala, maroon-mandala, tan-mandala, cream-mandala, cream-watercolor, yellow-half-mandalas, cream-curve, orange-mandala, folk-peacock, blue-mandala.

Replace any file with a higher-resolution original of the same name to sharpen it further.
